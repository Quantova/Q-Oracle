# Q Oracle

This repository holds the off chain translation layer for the Quantova gateway. Its nodes watch foreign chains, run their verification off chain, and produce post quantum attestations with proofs of correct verification. It is the one boundary where classical cryptography is allowed and nothing else may import it. No code lives here until the gateway phase. Governed by the crypto policy in the Quantova Specs repository. Commits are authored by the owner only. Dual licensed under Apache 2.0 and MIT.
